# 声账 · 可点击产品原型

这是“声账”产品原型阶段的独立交付，使用原生 HTML、CSS 和 JavaScript 编写，无构建步骤、无远程依赖。

## 运行

直接打开 `index.html`，或在当前目录启动静态服务器：

```bash
python3 -m http.server 4173
```

访问 `http://localhost:4173`。

## 评审重点

建议按以下主链路走通一次：

1. 首次引导 → 使用演示数据进入账本
2. 点击中央语音按钮 → 说出“午饭 25，打车 18” → 两笔账单自动入账 → 撤销
3. 打开一笔账单 → 编辑金额或分类 → 保存
4. 统计 → 点击每日柱状图 → 查看当日明细
5. 设置 → 微信登录 → 云备份 → 查看换机恢复冲突
6. 演示导航 → 检查网络失败、额度耗尽和麦克风拒绝状态

桌面端右侧的“演示导航”可直接跳到关键页面和异常状态。按下 `D` 也可打开或关闭。刷新页面会重置演示数据。

## 页面截图

`screenshots/` 中包含 390 × 844 移动端视口的关键页面截图，覆盖首次引导、账本、语音结果、统计、手动记账、分类管理、设置、云备份、恢复冲突、微信登录、导出恢复和异常状态。

`screenshots/qa-report.json` 记录了自动交互测试结果，`screenshots/layout-audit.json` 记录了页面横向溢出与触控尺寸检查。

## 当前边界

- 所有账单、分类和账号状态均为内存中的模拟数据。
- 麦克风、语音识别、微信登录和云备份均为交互演示，不连接真实服务。
- JSON 与 CSV 导出会使用演示数据生成真实文件，便于检查导出内容结构。
- JSON 恢复支持读取声账导出的演示备份；正式版本还需要补充签名、版本迁移和严格的数据校验。
- 原型聚焦交互和产品结构，不等同于最终视觉稿或生产代码。
