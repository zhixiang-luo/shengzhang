## 2. 延迟

从开始播放测试音频到结果返回：

| 阶段 | P50 | P95 |
| --- | --- | --- |
| 首段字幕 | 1.28s | 1.53s |
| 火山最终文字 | 3.25s | 8.40s |
| DeepSeek 结构化 | 0.86s | 1.23s |
| 总耗时（含完整音频播放） | 4.09s | 9.44s |

多笔长句本身可能持续 8–10 秒，因此“从开始说话算总耗时”会被音频长度拉长。按录音结束到结果返回折算：

- 松手到最终文字：约 P50 0.79s、P95 1.10s。
- 松手到结构化完成：约 P50 1.68s、P95 2.20s。

分场景松手后总耗时：

| 场景 | P50 | P95 |
| --- | --- | --- |
| 单笔 | 1.63s | 2.15s |
| 多笔 | 1.78s | 2.20s |
| 金额变体 | 1.70s | 2.09s |
| 日期 | 1.63s | 1.82s |

典型场景满足 P95 ≤ 5 秒目标。

- `46块80` 改为自然口语 `46块8`。
- 多笔之间加入“然后”停顿。
- 移除“旅游/旅行”“演出/其他”等多重分类歧义。
