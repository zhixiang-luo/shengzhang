## 2. 成本公式

每次语音请求的变量成本：

```text
单次成本 =
  ASR 音频秒数 / 3600 × ASR 每小时价格
  + LLM 输入 token × 输入单价
  + LLM 输出 token × 输出单价
  + 网关计算 / 日志 / 存储的摊销
```

每个活跃用户的月成本：

```text
月成本 = 日均语音次数 × 30 × 单次成本 + 备份存储 + 客服与支付摊销
```

付费产品的到手收入：

```text
到手收入 = 标价 - 渠道费 - 税费 - 退款准备
```

## 3. ASR 成本情景

按 5 秒一次、Qwen3-ASR 参考价 ¥0.79/小时计算，单次 ASR 约 ¥0.0011：

| 日均次数 | 每人每月 ASR 估算 | 1,000 人/月 | 10,000 人/月 |
| --- | ---: | ---: | ---: |
| 3 次 | ¥0.10 | ¥99 | ¥987 |
| 10 次 | ¥0.33 | ¥329 | ¥3,290 |
| 20 次 | ¥0.66 | ¥658 | ¥6,580 |

以上只是 ASR 最坏情景的近似，不含 DeepSeek、网关、对象存储、支付渠道、税费和客服。火山也与 SiliconFlow 的价格结构不同，必须以账单复核。

## 4. 19.9 元定价的风险

19.9 元扣掉支付渠道、税费和退款准备后，实际到手可能只有约 14–17 元。

- 如果用户长期每天打满 20 次，单是 ASR 就需要数月到数年的收入覆盖；
- DeepSeek、存储和客服会进一步拉长回收周期；
- “终身”意味着回收周期没有终点；
- 低价会吸引价格敏感用户，却不一定带来高留存或高质量口碑。

因此：

- 19.9 元仅作为限量创始支持包；
- 包含 12 个月 Pro，不承诺永久无限 AI；
- 标准会员优先做年费；
- 买断版必须等成本看板、续费和重度用户数据齐备后再决定。

## 5. 成本看板必须具备的字段

后端埋点和看板至少记录：

- 请求日期、供应商、模型版本；
- 音频秒数；
- ASR 耗时和失败码；
- LLM 输入/输出 token；
- 单次请求成本；
- 用户或匿名安装的额度类型；
- 活跃用户数和语音请求数；
- 备份大小、恢复次数和存储成本；
- 支付渠道费、退款和税费。

日志不得记录录音、转写正文、账单金额、分类明细、备注和 token 明文。
