# 声账 UI 交付规范

## 1. 目标与交付边界

本文档让设计师、开发者和后续 AI 能从原型独立产出高保真 UI 与 React Native 页面，不需要回看聊天记录。

- 原型：`prototype/index.html`，已完成交互评审。
- 视觉方向：`design/README.md` 与 `design/moodboard/README.md`。
- 资产命名与导出：`design/ASSETS.md`。
- 令牌源文件：`design/tokens/design-tokens.json`。
- 代码令牌：`apps/mobile/src/theme/tokens.ts`。
- 基准视口：390 × 844，iOS 安全区按 47/34pt，Android 使用系统 inset。
- 目标：温暖、克制、清爽；信息密度低；一屏一个主行动。

高保真交付以“可在 React Native 中逐像素实现”为准，不以 Figma 图层数量为目标。可编辑源文件和导出 PNG 必须同时保留。

## 2. 视觉原则

1. **纸感而非卡片堆叠**：背景使用奶油纸色，模块优先通过留白、字号和极淡分隔线组织。
2. **腮红只给主行动**：一屏最多一个腮红实心按钮；次要操作使用文字、描边或浅色底。
3. **金额是主角**：账本总额和账单金额使用等宽数字，右对齐，避免多余货币符号。
4. **小猪是印章**：只出现在空状态、引导和成功反馈，不进入原生启动图或 React 启动首帧，不做背景贴图或循环动画。
5. **状态必须可解释**：录音、上传、解析、保存、失败都有不同文案和视觉，不只换一个转圈。
6. **动效服务状态**：常态 140–280ms；尊重系统“减少动态效果”。

## 3. 设计令牌

### 3.1 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `color.canvas.default` | `#FAF7F0` | 页面背景 |
| `color.canvas.raised` | `#FFFDF8` | Sheet、浮层、输入区 |
| `color.canvas.sunken` | `#F3EEE5` | 选中底、图表轨道 |
| `color.ink.primary` | `#292624` | 标题、正文、金额 |
| `color.ink.secondary` | `#726B64` | 说明、次级信息 |
| `color.ink.tertiary` | `#A39A91` | 时间、占位、弱提示 |
| `color.accent.blush` | `#E89A96` | 主按钮、图表主色 |
| `color.accent.blushDeep` | `#9D5657` | 腮红上的可读文字、支出 |
| `color.accent.blushSoft` | `#F7DDD8` | 成功底、录音波纹 |
| `color.accent.sage` | `#9EAD98` | 收入、辅助图 |
| `color.accent.sand` | `#E1BD7B` | 提醒、第三组图 |
| `color.semantic.danger` | `#B34F48` | 删除、错误 |

禁止新增未登记的高饱和分类色。分类图标使用统一墨色；图表最多使用腮红、鼠尾草、沙金和暖灰四组。

### 3.2 字体

| 角色 | 字体 | 字号/行高 | 字重 |
| --- | --- | --- | --- |
| Hero 数字 | 系统等宽数字 | 48 / 52 | 500 |
| 页面标题 | Songti SC / 系统衬线 | 34 / 38 | 500 |
| 区块标题 | Songti SC | 24 / 30 | 500 |
| 卡片标题 | PingFang SC | 17 / 24 | 600 |
| 正文 | PingFang SC | 15 / 23 | 400 |
| 标签 | PingFang SC | 13 / 18 | 500 |
| 说明 | PingFang SC | 11 / 16 | 400 |

Android 无 Songti SC 时使用系统衬线或 `Noto Serif CJK SC`；不得为了视觉效果下载体积过大的字库。

### 3.3 间距与尺寸

- 8pt 基准：4、8、12、16、20、24、32、40、48、64。
- 页面左右边距：20pt。
- 列表行高：56–64pt；主按钮高度 52–56pt。
- 最小触控目标：44 × 44pt。
- 底部导航安全区以上高度：82pt；中央语音按钮 68pt。
- 卡片圆角：24pt；Sheet 顶部圆角：32pt；输入框：16pt。
- 浮层最大宽度：390pt，桌面预览居中。

### 3.4 阴影与层级

- 普通卡片：`0 2 10 rgba(67,54,45,0.04)`，可省略阴影改用分隔线。
- 浮层：`0 12 30 rgba(67,54,45,0.10)`。
- 语音按钮：`0 10 24 rgba(157,86,87,0.24)`。
- 不使用内阴影、玻璃模糊和多层投影。

### 3.5 动效

- 页面切换：淡入 + 8pt 位移，200ms。
- Sheet：面板从底部进入，蒙层独立淡入淡出；关闭时只有面板下滑，蒙层原地渐隐。
- 录音波纹：只响应真实音量，停止后 120ms 收敛。
- 成功：腮红圆一次扩散，280ms，不撒花。
- 撤销倒计时：线性进度条 8 秒，不做闪烁。

## 4. 页面与状态清单

所有页面使用同一手机壳和安全区。截图为 390 × 844、3× 导出；Figma 页面和代码路由使用同一命名。

### 4.1 首次引导

- 页面：小猪印章、标题“说一句，就记好。”、两句说明、主按钮“开始记账”。
- 次操作：“已有备份，前往恢复”。
- 无登录、无权限请求。
- 状态：首次、跳过引导、系统大字体。

### 4.2 账本空态

- 月份标题、支出/收入/结余骨架、今日空态、小猪侧影。
- 文案：“第一笔，说一句就好。”
- 中央按钮按住录音、松手提交，上滑 36pt 取消，向下回到 16pt 内恢复，向右滑 48pt 切换手动记账。
- 浮层固定展示“上滑取消”和“右滑手动记账”两个提示；取消态变红，手动态变金色。
- 不显示复杂教程或卡片轮播。

### 4.3 账本正常态

- 顶部：月份、设置入口。
- 顶部右侧同时提供搜索与设置两个 44×44 入口，顺序为搜索、设置。
- 摘要：本月支出 34pt，收入与结余 13pt。
- 今日区、日期分组列表、每日小计。
- 单笔账单可向左滑动露出固定宽度“删除”，不进入编辑页；删除手势需横向移动 24pt 才激活、52pt 才展开，纵向滚动优先。
- 最近账单最多展示本月全部数据，滚动加载。
- 底部导航：账本、语音、统计。
- 状态：今日无账单、删除后 8 秒撤销 Toast、备份状态小点。
- 账本与统计切换统一使用淡入淡出，不出现空白页横向滑入。

### 4.4 按住录音

- 页面轻微压暗，底部出现录音层。
- 语音面板支持左右滑：向左滑取消，向右滑切换到手动记账。
- 非空账本不展示常驻手动记账按钮；空账本保留“加一笔”直接入口。
- 按住后直接出现浮层并自动请求麦克风；浮层实时显示转写文字。
- 松手立即把实时文字结构化；字段完整时直接写入账本，再显示“已记好”结果卡。
- 录音阶段显示真实计时与电平反馈，错误时提供重新录音和手动记账。
- 波形、计时 `00:03`、提示“松手记账，左滑取消，右滑手动”。
- 按钮放大 4%，环形进度随 30 秒推进。
- 左滑超过 80pt 后进入取消态；右滑超过 80pt 后进入手动记账。
- 状态：权限请求、录音中、取消中、过短提示。

### 4.5 识别中

- 保留最近账单作为背景。
- 文案按阶段切换：“正在听清……”→“正在整理账单……”
- 显示真实声波收束动画，不使用无限假进度条。
- 可取消，取消后无账单。

### 4.6 入账结果卡

- 底部 Sheet，标题“已记好”或“已记好 N 笔”，逐笔展示金额和分类。
- 每笔：分类路径、备注、金额、时间。
- 主操作“收好”关闭结果卡；次操作“撤销”在 8 秒内整批删除本批账单。
- 结果出现时账本已经更新，不再出现“确认记账”作为默认路径。
- 多笔超过可视高度时列表可滚动，标题与撤销条固定。
- 状态：保存中、单笔已记好、多笔已记好、保存失败、撤销成功。

### 4.7 缺金额修正

- 底部 Sheet，标题“还差一个金额”（缺多笔时为“还差 N 个金额”），副标题“补上后，N 笔一起记好”。
- 顶部显示原始转写；下面按说话顺序列出本批全部条目。已有金额的条目只读显示（已有金额的修改在入账后点结果卡逐笔进行）；缺金额的条目高亮，标注“分类 · 没听到金额”，并带一个金额输入框（¥ 前缀、小数键盘、高度 48pt）。第一个缺失项自动聚焦。
- 金额严格解析为整数分：只接受数字、至多两位小数，可带 ¥/￥ 前缀和 元/块 后缀，全角数字按半角处理；逗号、“万”、字母、运算符、第三位小数一律拒绝并在行内提示，不做静默改写；0 与超过九位整数的金额同样拒绝。
- 主按钮“确认入账”，未补齐或有输入问题时禁用；次按钮“放弃”，整批不保存、不保留转写，按钮上方提示“放弃则这 N 笔都不记”。
- 点遮罩或按返回键：键盘弹出时只收键盘，再次点击才放弃。iOS 小数键盘没有回车键，列表拖动也会收起键盘。
- 一批只能决定一次：已放弃的不能再确认，已确认的不能再放弃。
- 确认后沿用同一 `requestId` 以单事务写入，复用“已记好 N 笔”结果卡与 8 秒整批撤销；面板完全关闭后才出现结果卡。
- 面板打开期间忽略新的录音。
- 状态：缺金额、输入有误、可确认、已确认、已放弃。

### 4.8 手动记账

- 单页 Sheet：支出/收入 Segmented Control、大金额输入、分类网格、日期、备注、计算键盘。
- 金额使用单行卡片展示，关闭输入框内部滚动，长金额自动缩放字号。
- 金额不使用系统数字键盘：页面底部展示 4×4 计算键盘，支持数字、小数点、`+ − × ÷` 和删除；保存时按运算优先级计算为整数分。
- 计算键盘默认收起，只有点击“花了多少/收到多少”标签或金额框时进入编辑态并展开；点击页面其他位置或开始滚动时自动收起。
- 金额区点击后关闭备注系统键盘并重新显示计算键盘，金额表达式本身不显示原生光标。
- 分类区提供“新建分类”，可选择新增一级分类或当前一级分类下的二级分类。
- 时间使用月历 Sheet：星期一开始的 42 格月视图、选中日、今日标记、前后月份切换、24 小时与 0–59 分钟选择。
- 不提供日期文本输入，避免格式和数据库时间不一致。
- 最近使用分类置顶；分类支持搜索。
- 主按钮固定在键盘上方。
- 备注获得焦点时隐藏计算键盘，自动滚动到输入法上方；关闭系统键盘后计算键盘保持收起。
- 备注采用单行“备注 / 选填”字段，文字和光标垂直居中，占位文案使用完整示例而不是只重复分类名。
- 编辑态显示“删除”文本按钮。
- 状态：新建、编辑、金额非法、分类归档、删除确认。

### 4.9 月度统计

- 月份切换、支出/收入切换。
- 大数字总额、较上月变化。
- 每日柱状图：默认当月全部日期；点击柱显示当天收入/支出明细。
- 分类占比：按金额排序的完整一级分类列表，不省略任何分类。
- 分类行可点击下钻二级分类金额。
- 展示日均支出和最高支出日。
- 日均与最大支出日使用两列信息，不做独立卡片墙。
- 状态：无数据、只有收入、上月为空、日期下钻。

### 4.10 日期明细

- 顶部日期和当日收支小计。
- 分类构成条 + 账单列表。
- 点击账单进入编辑 Sheet。
- 返回保留统计滚动位置。

### 4.11 分类管理

- 支出/收入切换。
- 两级列表，一级可展开；同级通过长按分类行主体约 400ms 后调整顺序，单击不触发拖拽，松手后持久化。隐藏项折叠到“已隐藏”并支持恢复。
- 新增分类输入名称、选择图标和颜色，颜色仅限令牌色。
- 分类新增/编辑 Sheet 在键盘弹出时使用高度避让和焦点滚动，输入框、错误提示与操作按钮不得被键盘遮挡。
- 被引用分类的删除按钮改为“归档”，说明历史账单保留。

### 4.12 微信登录

- 标题“换手机，也能找回账本”。
- 说明仅用于云备份和恢复，不读取好友或朋友圈。
- 微信绿色只出现在官方登录按钮，页面主色仍是奶油与墨色。
- 状态：授权中、取消、未安装微信、网络失败。

### 4.13 云备份

- 状态卡：未开启、待备份、备份中、成功、失败。
- 成功显示最近时间、大小和账单数。
- 主操作“立即备份”，次操作“从云端恢复”。
- 恢复冲突页必须展示本机与云端的时间、账单数，并要求明确选择。

### 4.14 设置与数据管理

- 分组：本机数据、分类、效率、数据与账号、隐私、帮助与反馈、更新、关于。
- “效率”分组提供“付款页快捷记账 / 一键读取付款结果”，说明仅 Android 11+ 原生包可用。
- 语音偏好：自动入账/先确认、今日剩余次数。
- 数据安全入口显示本机账单数、分类数、最近导出时间，并提供导出 JSON、导出 CSV、从 JSON 恢复和清空本机账本。
- 退出登录说明本机账本保留。
- 危险操作使用文字按钮和二次确认，不用大面积红色卡片。

### 4.14.1 数据安全页

- 顶部深色说明卡文案：`账本默认只保存在本机，你可以随时带走。`
- 三项统计：本机账单、分类、最近导出。
- 常规分组：导出 JSON、导出 CSV、从 JSON 恢复。
- 危险分组：清空本机账本，使用危险色文字，不使用大面积红色背景。
- 恢复前展示备份导出时间、App 版本、账单数和分类数；本机非空时追加一次覆盖确认。
- 错误卡必须说明“当前账本没有被修改”，并给出可重试动作。

### 4.14.2 改进与反馈页

- 设置中提供“帮助与反馈”分组，入口行文案为“改进与反馈 / 问题或建议”。
- 顶部深色说明卡明确“反馈会直接给到独立开发者”，并说明匿名可提交、联系方式选填。
- 类型 Chip 六选一：功能建议、使用问题、语音识别、记账结果、数据安全、其他；触控高度不低于 44pt。
- 详情为多行输入，10–1000 字并显示计数；联系方式单行选填，最多 200 字。
- 匿名诊断开关默认开启，只说明 App 版本、系统版本、当前页面和错误码；必须写明不附带金额、分类、备注、录音和转写。
- 发送中禁止重复提交；发送失败保留全部输入；同一失败请求重试复用幂等 ID。
- 成功页显示反馈编号、联系回复说明和“再提一条”，不跳转到外部网页。

### 4.14.3 付款页快捷记账设置

- 标题“付款页快捷记账”，顶部说明文案：`付完款，点一下“声账记账”`；副文案解释从控制中心读取当前微信/支付宝付款成功页，先确认再入账。
- 系统能力卡两行：`系统能力 / Android API`、`读取服务 / 已开启或未开启`，状态点使用成功色/中性色。
- 第一步“开启‘声账快捷记账’”：明确只读取微信、支付宝付款结果页，只有点击磁贴时读取一次，不后台持续监听；点击后跳系统无障碍设置。
- 第二步“添加控制中心磁贴”：Android 13+ 先调用系统添加请求，失败或 Android 11/12 显示手动路径“下拉控制中心 → 编辑磁贴 → 添加‘声账记账’”。磁贴正式标签必须是“声账记账”。
- “看一眼确认卡”入口打开 `/screen-capture?demo=1` 微信支付示例，必须标明预览不写账本。
- 使用方式固定三步：付完款停在成功页 → 下拉控制中心点磁贴 → 核对后记好这一笔。
- 隐私卡固定文案覆盖：只读微信/支付宝白名单、不读订单号/余额/银行卡、截图不进相册不上传、最长 5 分钟自动清理。
- iOS 显示“iPhone 的系统限制”，说明后续走快捷指令截屏 → App Intent/确认页；Expo Go/Web 明确不支持真实读屏，不展示可开启的假入口。

### 4.14.4 付款页确认卡

- 入口由原生磁贴/无障碍服务打开 `shengzhang://screen-capture`；页面背景优先弱化本次付款页截图，无截图时使用墨色品牌背景。状态栏图标必须使用浅色。
- 顶部左侧关闭，中间显示“微信支付/支付宝 · 刚刚读取”或“界面预览”；关闭即取消本次草稿，不写账本。
- 主体为底部浅奶油色确认面板。标题 `PAYMENT FOUND / 识别到一笔账单`，副文案“金额和内容都可以直接改，确认后才入账”，右侧显示“已识别 / 请核对 / 需补充”置信度。
- 支出/收入使用两段切换；金额卡显示 `−¥` 或 `+¥`、大字号金额与“修改”。点击金额复用计算键盘，不出现原生输入框滚动条。
- 分类横向展示一级分类，下面展示二级 Chip；一级入口“新建分类”和二级入口“新建子分类”均复用 `CategoryEditorSheet`。默认分类可由商户/内容推荐，但用户可随时修改。
- 时间行复用月历与时间 Sheet，显示“今天/昨天/前天”或日期及 HH:mm，不允许手输格式。
- 商户/内容为单行输入，最多 40 字，占位示例“例如：滴滴出行”。
- 低置信度、多金额、OCR 失败和手动补金额使用浅色警告卡，不用红色大面积错误；页面文字不足时提示“正在本机识别截图…”，失败后可重试或直接改金额。
- 底部固定“取消 / 记好这笔”。保存成功后同一卡片切换为“已记好这笔”，显示带收支符号的最终金额和内容，并提供“撤销”和“N 秒后返回账本”，倒计时 8 秒。
- Demo 模式所有编辑可体验，但保存只展示成功态，不写 SQLite；真实模式同一 `captureId` 重复保存只能生成一笔。
- 状态：loading、unsupported、setup_required、empty、ready、ocr_running、low_confidence、saving、saved_with_undo、undone、expired/invalid capture。

### 4.15 搜索账单

- 顶部返回、标题“搜索账单”；默认结果标题为“最近账单”。
- 搜索框固定 54pt 高、圆角 18pt，左右 20pt 页边距；输入区固定 52pt 高，关闭上下内边距并设置垂直居中，占位词和用户输入使用同一文字基线。支持清除关键词。
- 收支类型使用三段 Segmented Control，筛选按钮显示有效条件数量。
- 展开筛选后按支出/收入分组展示一级与二级分类 Chip；日期和金额范围各占一行。
- 开始和结束日期是 44pt 高的可点击字段，不提供文字输入。点击后复用 `DateTimePickerSheet` 的 `date` 模式；未选择时显示“选择开始日期/选择结束日期”，选择后显示 `YYYY-MM-DD`，已选择字段提供独立清除按钮。
- 最低和最高金额使用 44pt 高输入框，`paddingVertical: 0`、固定行高、`textAlignVertical: center`，Android 关闭字体额外留白，金额和占位词均垂直居中。
- 条件非法时在面板内显示中文错误，并以禁用态阻止“应用”；无结果状态给出放宽或清除筛选动作。
- 结果行复用分类图标与金额符号规则，展示备注/分类、分类路径、日期时间、金额和进入编辑的箭头。
- 页面动效使用右侧滑入，键盘使用平台安全避让；返回账本不改变月份。

### 4.16 月度回顾与分享

- 统计页在空/非空月份都显示“这个月，过得怎么样？”入口；入口最小高度 74pt，主动作不依赖金额。
- 回顾页顶部显示返回、标题“本月回顾”和 `YYYY年M月`；事实卡不使用消费评价或排行榜。
- 有数据时展示事实文案、支出/收入/结余、日均、最高支出日、最大分类、语音笔数和分享入口。
- 空月份展示品牌标记、“这个月还很安静”、解释文案和“记下第一笔”。
- 分享预览使用底部弹层，卡片固定 4:5；预览在用户点击“分享 PNG”前不得触发系统分享。
- 分享卡只展示月份、账单笔数、分类占比区间、趋势方向、语音笔数和品牌 CTA。
- 分享中锁定关闭按钮，显示“正在生成高清图片”；失败使用中文恢复文案，不展示原生异常原文。
- 预览弹层、主页面滚动和分享卡之间必须有明确层级，关闭预览后不改变统计月份和账本数据。

### 4.17 异常状态

至少交付：

- 麦克风拒绝；
- 网络失败；
- 语音额度耗尽；
- 服务超时；
- 微信未安装；
- 微信授权取消；
- 备份失败；
- 恢复校验失败；
- 本机存储空间不足。

每个异常只显示一个主恢复动作，必要时提供“手动记账”兜底。

## 6. 图表规格

### 6.1 每日柱状图

- 高度 176pt，绘图区上下留 20pt。
- 柱宽根据天数：7 日 24pt，31 日 6pt，最小间距 2pt。
- 支出使用腮红，收入使用鼠尾草。
- 仅显示 1、5、10、15、20、25、月末标签，避免拥挤。
- 点击命中区域至少 32pt 宽，选中柱加深，顶部浮层显示日期和金额。
- 空数据保留坐标和一句“这个月还没有记录”。

### 6.2 分类占比

- 环形图外径 164pt，环宽 18pt，中心显示总支出。
- 分类最多取前 4 项，其余合并为暖灰“其他”。
- 列表显示颜色点、名称、金额和百分比。
- 百分比按整数分计算，最后一项吸收四舍五入差值，合计必须 100%。

## 8. iOS 与 Android 差异

- 使用系统 SafeArea，不写死刘海高度。
- iOS 使用 `PingFang SC` 和 `Songti SC`；Android 使用 `Noto Sans CJK SC` 与 `Noto Serif CJK SC` 回退。
- Android 返回键关闭 Sheet，不退出应用；iOS 支持边缘滑动关闭。
- Sheet 与录音浮层必须覆盖整屏并拦截触摸，不能在弹层打开时把点击透传给账单列表或分类列表。
- 触觉反馈在 Android 上降级为轻触，不假设同等硬件。
- 微信 SDK 返回与未安装状态必须在双端分别测试。
- 字体放大到 1.3× 时，金额和按钮不截断；列表标题允许两行。

## 9. 无障碍

- 正文对比度 ≥ 4.5:1，大号文字 ≥ 3:1。
- 所有图标按钮提供中文 `accessibilityLabel`。
- 图表提供一句可读摘要，例如“本月支出 1280 元，餐饮最多，占 42%”。
- 录音按钮说明“按住录音，松手提交，左滑取消，右滑手动”。
- 不只是用颜色表达收入/支出，同时使用 `+`、`−` 和文字。
- 撤销窗口不能成为唯一的删除恢复方式。
- 尊重系统减少动态效果和字体缩放。

## 10. 交付结构

高保真阶段在 `design/` 下维护：

```text
design/
├── tokens/                 JSON 与 CSS 令牌
├── assets/                 品牌 SVG、图标
├── screens/                每页 PNG，按编号命名
├── source/                 可编辑源文件（Figma 导出或代码稿）
├── specs/                  页面标注和组件规格
└── README.md               索引与验收说明
```

推荐同时维护一个代码优先的可视化页面，以便截图自动化和 token 一致性检查；不要让 Figma 成为唯一可编辑来源。

命名示例：

```text
design/screens/03-ledger-normal.png
design/screens/04-voice-recording.png
design/screens/04-voice-recording-cancel.png
design/screens/08-stats-empty.png
```

## 11. React Native 映射

- `design/tokens/design-tokens.json` 是设计源；`apps/mobile/src/theme/tokens.ts` 是代码镜像。
- 页面文件名与 Expo Router 路由保持一致。
- 组件 props 使用语义命名，不直接传十六进制色值。
- 图表尺寸使用 pt，不按截图比例硬缩放。
- 常规页面动画优先使用 Reanimated shared value；启动层为与原生死屏衔接，使用 React Native Animated + native driver，并通过惰性 state 创建稳定动画值。
- 图片资产按 1×/2×/3× 或 SVG 提供；品牌图标优先 SVG。

## 12. 启动与输入状态

- 原生启动图使用 `design/assets/splash-wordmark.svg` 导出的奶油底横向字标；只显示“声账”和极小声波，不使用圆形底盘、小猪、缺省侧弧、旋转菱形或被裁切的装饰。
- 启动动画按 App 进程生命周期分档：首次安装播放完整 2.72 秒版本；后续每次进程冷启动播放 1.2 秒快速版本；仅从后台恢复时不播放。
- 首次完整动画播放完成后通过 `shengzhang.bootIntroVersion` 记录；快速版本只用于区分首次安装，不改变后台恢复路径。React 首帧复用原生 Splash 的字标、比例、声波高度与透明度，再从同一画面展开光晕、主张和账本状态，避免白屏与视觉跳变。
- 首次麦克风授权完成后只显示可关闭的就绪提示，不自动创建录音会话；用户再次按住后才进入录音。
- 新建手动账单时默认展开金额键盘，并在金额末尾显示短光标；编辑已有账单时键盘默认收起。
- 点击分类、时间、备注、页面空白或开始滚动都会收起金额键盘。
- 本月支出深色卡片使用暖棕、腮红半透明圆形和细轮廓装饰，装饰层不参与点击，金额与收支信息仍处于最高视觉层级。
- 账本列表、统计分类、分类管理、一级/二级分类选择器和自定义分类编辑均使用同一套线性 `CategoryIcon`。自定义分类可选择图标，缺失值回退到 `other`。
