# 信息架构

## 1. 顶层结构

声账只保留两个主页面和一个中心主行动，降低导航和认知负担。

```text
账本
├── 月份与收支总览
├── 今日账单
├── 最近账单
├── 手动记一笔
└── 设置

语音记账（底部中心主按钮）
├── 录音
├── 识别中
├── 入账结果
└── 修正

统计
├── 月份切换
├── 支出/收入切换
├── 每日趋势
├── 分类占比
└── 日期明细
```

## 2. 主导航

底部导航采用“左侧账本、中心语音、右侧统计”的不对称结构。

- 左：`账本`
- 中：大尺寸语音按钮，按住说话
- 右：`统计`

设置不占导航位，从账本右上角进入。右上角不再放手动记账加号；非空账本的手动入口位于语音面板向右滑动，空账本保留“加一笔”按钮。

## 3. 页面清单

| 页面 | 目的 | 主要入口 | 主要出口 |
| --- | --- | --- | --- |
| 游客引导 | 说明核心玩法与权限 | 首次启动 | 空账本 |
| 账本 | 浏览当前月账单 | 主导航 | 语音、手动记账、统计、设置 |
| 语音录音态 | 捕获一句话 | 中心按钮 | 识别中、取消 |
| 识别中 | 表达处理中 | 松手 | 结果卡、修正、失败态 |
| 入账结果卡 | 确认已保存并允许修正 | 识别成功 | 编辑、撤销、关闭 |
| 手动记账面板 | 完整兜底录入 | 语音面板右滑、空账本加一笔、错误态 | 保存返回 |
| 统计 | 查看月度结构与趋势 | 主导航 | 日期明细、分类下钻 |
| 日期明细 | 查看某天账单 | 图表某日 | 编辑账单 |
| 设置 | 管理分类、账号、数据 | 账本右上 | 分类、账号、备份、隐私 |
| 微信登录页 | 完成一键授权 | 备份提示、设置 | 备份状态 |
| 云备份页 | 查看状态、手动备份与恢复 | 设置、登录成功 | 恢复确认 |
| 分类管理 | 调整分类体系 | 设置 | 编辑分类 |

## 4. 账本页面结构

从上到下：

1. 月份、设置入口。
2. 本月支出、收入、结余摘要。
3. 今日账单与今日收支。
4. 本月最近账单，按日期分组。
5. 底部中央语音按钮。

账本为空时，保留同样骨架，只把账单区域替换成简洁空状态和“说第一笔”入口。

## 5. 统计页面结构

从上到下：

1. 月份切换与支出/收入切换。
2. 大数字总额和较上月变化。
3. 每日柱状图，可点击日期。
4. 分类占比与分类列表。
5. 日均支出、最大支出日。

不设置独立筛选抽屉。首版筛选通过点击图表或分类自然下钻完成。

## 6. 页面状态

- 账本：空、正常、加载本地数据、删除后撤销。
- 语音：未授权、按住中、上滑取消、识别中、成功、缺金额、网络失败、额度耗尽。
- 登录：未登录、授权中、已登录、取消、微信未安装。
- 备份：未开启、待备份、备份中、成功、失败、恢复中。
- 统计：无数据、正常、当前月无记录。

## 7. 导航规则

- 主导航切换保留当前月份和滚动位置。
- 语音与登录以底部 Sheet 呈现，关闭后回到原页面。
- 识别完成自动关闭录音态，结果卡浮在账本上。
- 手动记账保存后回到触发页面，不新增中间成功页。
- 语音面板左滑取消并关闭，右滑关闭语音并进入手动记账。
- 云端恢复完成后直接刷新账本和统计。
