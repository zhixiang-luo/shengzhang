# 可信语音与月末回顾专项

日期：2026-10-20
状态：M7/M8 执行规格
上位文档：[后期产品战略](./21-post-mvp-strategy.md)

## 1. M7：可信的一句话

### 1.1 目标

让默认路径真正符合“说一句，就记好”：

```text
按住说话 -> 松手 -> 云端识别 -> 自动保存 -> 显示“已记好” -> 8 秒内可整批撤销
```

用户不需要为了保存再点一次“确认记账”。

### 1.2 决策规则

| 情况 | 行为 | 原因 |
| --- | --- | --- |
| 1–5 笔，金额和分类完整 | 自动保存 | 主路径必须一步完成 |
| 金额缺失 | 不保存整批，进入补金额 | 不允许模型猜金额 |
| 分类无法匹配 | 落到“其他”，结果卡提示可修改 | 分类错误比打断更可修复 |
| 结构化失败或网络失败 | 不保存，提供重试和手动记账 | 不制造半批账单 |
| 用户主动选择“每次先确认” | 显示确认卡 | 这是偏好，不是默认 |

### 1.3 结果卡

保存成功后显示“已记好”或“已记好 N 笔”，而不是“要记这几笔吗？”。

必须展示：

- 本批总金额；
- 每笔分类、备注和金额；
- “撤销”操作；
- 8 秒撤销窗口；
- 关闭后回到账本。

撤销必须按 `voiceRequestId` 整批软删除。若用户已单独修改某一笔，后续版本需要区分“仅撤销未修改项”和“全部撤销”，不能静默扩大撤销范围。

### 1.4 质量门禁

自动化 TTS 基线只能证明链路和结构化稳定。M7 完成前还需要：

1. 30–50 条真人语音，覆盖口音、语速、吞字、环境噪声和手机麦克风差异；
2. iPhone 小屏、主流 iPhone、主流 Android 中低端设备；
3. 正常网络、弱网、断网、供应商超时；
4. 麦克风拒绝、中途撤回、额度耗尽；
5. 同一句话重复提交不产生重复批次；
6. 结果卡关闭、自动关闭和撤销之间不出现幽灵账单。

### 1.5 验收

- [ ] 完整结果默认自动写入 SQLite。
- [ ] 保存成功后账本和统计立即刷新。
- [ ] 8 秒内撤销后账单和统计恢复。
- [ ] 缺金额时不写入任何一笔。
- [ ] 网络和解析失败不覆盖已有账本。
- [ ] 真人测试集金额准确率达到门槛。
- [ ] P50/P95 延迟和失败码可记录。

## 2. M8：有感觉的月末回顾

### 2.1 用户任务

> 月底我想用一分钟知道这个月钱大概花在了哪里，而不是看一堆报表。

月末回顾的第一个版本必须只使用本地、确定的数据，不把用户的账本正文上传给生成模型。

### 2.2 回顾内容

首版包含：

- 本月支出和收入总额；
- 最大的一级分类及占比；
- 与上月的变化；
- 日均支出；
- 最高支出日；
- 语音入账笔数或使用次数；
- 一句克制的回顾文案。

可选展示：

- 最常出现的备注主题，但必须本地聚合且默认不展示原文；
- 与上月相比变化最大的分类；
- 本月最安静的一天或消费最集中的一天。

不展示：

- 对他人的评价；
- “你应该少花”式指责；
- 没有数据依据的节省金额；
- 排行榜；
- 不透明的消费人格标签。

### 2.3 文案风格

示例：

> 这个月，餐饮是你最常回到的地方。
> 10 月 12 日是支出最高的一天。
> 你说了 43 句话，账本替你整理好了 68 笔。

文案先说事实，再给轻量感受，不给财务建议。

### 2.4 分享卡

分享必须由用户主动触发，并提供预览。

默认隐藏：

- 具体金额；
- 备注原文；
- 具体商户；
- 日期中的敏感信息。

默认可以展示：

- 分类占比区间；
- 月度趋势；
- 语音笔数；
- 一句不包含敏感数字的回顾。

用户可以选择展示具体金额，但不得默认开启。分享卡底部入口为“我也来记一句”。

### 2.5 实现顺序

1. 本地统计聚合和回顾文案规则；
2. 月度回顾页；
3. 分享卡 PNG 生成和系统分享；
4. 埋点：打开、完成预览、分享、被分享后安装；
5. 验证后再评估 AI 文案，只允许基于本地确定的统计事实生成。

### 2.6 验收

- [ ] 所有回顾数字与统计页一致。
- [ ] 无数据月份有合理空状态。
- [ ] 分享前有预览和隐私选项。
- [ ] 默认分享不包含金额、备注和商户原文。
- [ ] 分享卡在 iOS 和 Android 的主流尺寸可读。
- [ ] 关闭分享后不影响账本和统计。

## 3. M9：数据安全品牌化

### 3.1 产品表达

对用户的一句话：

> 说完就忘：录音只用于本次识别，识别完成后丢弃；转写不进入日志，也不用于训练。

小猪角色可以使用：

> 你只管说，小猪听完就忘。

该文案只能在上线前完成日志、供应商留存、临时文件和 SDK 检查后使用。

### 3.2 隐私中心

设置中的隐私中心至少展示：

- 麦克风什么时候被使用；
- 录音上传到哪里、何时删除；
- 哪些数据在本机；
- 哪些数据在云端；
- 云备份是否开启；
- 导出全部数据；
- 删除本机数据和云端数据；
- 第三方 SDK 清单。

### 3.3 验收

- [ ] 录音请求结束后本地临时文件不存在。
- [ ] 服务端不保存原始音频和转写正文。
- [ ] 日志搜索不到账单正文、备注、token 和微信标识。
- [ ] 游客可以完整使用本地记账和统计。
- [ ] 云备份对象不可公开读取。
- [ ] 删除数据后旧快照不会重新上传。
