# 声账 MVP 产品需求文档

## 1. 文档信息

- 产品名称：声账
- 副标题：一句话语音记账
- 品牌主张：说一句，就记好。
- 版本：MVP 1.0
- 平台：iOS、Android
- 市场：中国内地
- 语言与币种：简体中文、人民币
- 产品阶段：可上架 MVP

## 2. 产品定位

声账面向 18–35 岁学生和年轻职场人，解决“付款后不想打开复杂记账应用”的问题。用户按住语音按钮说一句自然语言，系统识别金额、收支类型、分类、日期和备注，自动生成账单，并允许撤销或修改。

产品不是全功能财务管理系统。首版只做个人日常收支记录，以最低录入成本、清爽视觉和可信的统计结果建立差异。

### 核心用户任务

> 我刚付完钱，希望几秒内把这一笔或几笔记下来，之后能看懂这个月钱花在了哪里。

Android 11+ 另提供可选捷径：付款成功页下拉控制中心，点击“声账记账”，读取当前页面并进入可编辑确认卡。它减少“付款后再打开 App”的一步，但不替代语音主路径。

## 3. 产品原则

1. 语音是主路径，手动记账是稳定兜底。
2. 首次使用不强制登录，游客可以直接记第一笔。
3. 一屏只保留一个主行动，不制造多层入口。
4. 自动入账必须有明确结果反馈和可撤销能力。
5. 统计先保证准确和可读，不堆叠预测、排行和复杂指标。
6. 界面亲切但不幼稚，小猪只作为克制的品牌角色。

## 4. 目标与成功指标

### 用户目标

- 新用户在 30 秒内完成第一笔记账。
- 用户从打开 App 到语音入账完成不超过 5 秒。
- 用户能在一个月内清楚看到每日支出和分类构成。

### 产品指标

| 指标 | MVP 目标 |
| --- | --- |
| 首次记账完成率 | ≥ 80% |
| 首次会话语音使用率 | ≥ 60% |
| 语音松手至入账 P50 | ≤ 3 秒 |
| 语音松手至入账 P95 | ≤ 5 秒 |
| 金额识别准确率 | ≥ 98% |
| 收支类型识别准确率 | ≥ 95% |
| 一级分类首选准确率 | ≥ 90% |
| 第 7 日留存 | ≥ 25% |
| 7 日内严重崩溃率 | < 0.5% |

行为事件只记录匿名、最小化事件，不上传账单正文、分类明细或录音。

## 5. 用户与场景

### 主要用户

- 有日常消费但不愿维护复杂表格的学生和年轻职场人。
- 曾安装记账应用，但因录入步骤多、分类难找、界面杂乱而放弃的人。
- 希望偶尔回看月度消费，而不是做专业财务分析的人。

### 高频场景

- 午饭、咖啡、打车后立即记一笔。
- 一次说清多笔：“早饭 12，打车 30”。
- 第二天补记：“昨天晚饭 68”。
- 发工资、收红包、退款时记录收入。
- 月底查看每日支出、分类占比和最大支出日。

## 6. 范围与优先级

### P0：首版必须完成

- 游客模式、首次引导、语音权限说明。
- 按住录音、左滑取消、右滑手动记账、网络识别和自动入账。
- 一句话 1–5 笔、支出/收入、中文金额、相对日期、分类和备注。
- 自动入账结果卡、逐笔编辑、8 秒整批撤销。
- 缺金额修正、网络失败、额度耗尽、权限拒绝等关键异常。
- 手动记账、编辑、删除、月份账本和日期分组。
- 两级分类、内置分类、自定义分类、排序和归档。
- 月统计、每日图表、分类占比、日期明细。
- 离线账单搜索、确定性月度回顾和默认脱敏的分享卡。
- JSON 备份导入、CSV 导出、删除全部数据。
- 隐私说明、权限说明、账本离线可用。
- Android 11+ 付款页快捷记账：快捷设置磁贴、微信/支付宝无障碍文本读取、文本不足时端侧 OCR、可编辑确认卡、`screen` 来源和原地撤销。

### P1：首版之后

- 账号登录、云备份、游客账本合并和换机恢复。
- 实时多端同步与冲突合并。
- 预算、年度报表、桌面小组件。
- 周期记账、深色模式。
- 微信登录账号注销和更多恢复版本。
- 可选展示金额等更细粒度分享设置。

`0.2.0` 已完成本地账单搜索、确定性月度回顾和默认脱敏分享卡；后续继续验证大账本性能、双端系统分享和真机输入体验。

### P2：暂不承诺

- 多账本、家庭共享、多人分账。
- 资产、负债、转账、报销和投资。
- 银行或支付平台账单自动导入。
- 支付通知监听、后台自动记账、支付平台接口自动导入和发票识别。截图 OCR 仅作为 Android 付款页快捷记账的本地兜底，不是独立后台上传能力。
- 广告、公开社交和游戏化养成。

会员和邀请机制不属于 MVP。它们只在语音可信、真人评测、云备份、留存和成本门禁达标后，按 [后期产品战略](./21-post-mvp-strategy.md) 进入实验；具体限制见 [会员与增长方案](./23-membership-and-growth.md)。

## 7. 功能需求

### 7.1 首次启动

- 直接进入游客空账本，不显示强制登录。
- 空账本首次进入时展示一次轻量说明，介绍“按住说话、松手入账、单笔可改”，并提供手动记账入口。
- 首次点击语音时先解释麦克风、云端识别、录音处理和“不上传历史账单”的边界，再进入系统授权；用户拒绝后仍可手动记账。

### 7.2 语音记账

- 账本底部中央按钮本身就是录音控件：按下立即进入录音，松手直接提交；不先打开中间面板，也不要求再点击“语音入账”。
- 点击语音入口后显示操作面板：向左滑取消，向右滑切换到手动记账。
- 按住按钮开始录音，松手提交；向左滑取消，向右滑切换手动记账。
- 单次最长 30 秒，一句话最多生成 5 笔。
- 默认每天 20 次语音解析额度，由服务端远程配置；每次解析无论生成几笔计一次。
- 识别成功后自动保存，并展示“已记好”结果卡。
- 结果卡支持逐笔编辑和 8 秒整批撤销；进入单笔编辑后结束本批结果卡，避免已修改账单被后续整批撤销误删。
- 金额缺失时不保存整批，打开修正面板补齐；分类不确定时保存最优结果并允许修改。
- 无网络、额度耗尽或服务异常时提供明确原因、重试和手动记账入口；失败面板保持打开，已有转写在重试时复用，转手动记账时作为备注预填。
- 设置中可切换“自动入账”和“每次先确认”，默认自动入账；先确认是偏好，不是主路径。

### 7.3 手动记账与账本

- 账本非空时不展示独立“记一笔”按钮；从语音面板向右滑进入手动记账。
- 空账本保留一个“加一笔”直接入口，降低首次使用门槛。
- 手动记账页提供“新建分类”，可新增当前收支类型的一级分类或所选一级分类下的二级分类。
- 日期和时间不使用文本输入，改为点击日期卡片打开月历与小时/分钟选择面板。
- 手动记一笔只使用单页面板，支持支出/收入、金额、分类、时间、备注。
- 数字键盘支持基础四则运算，金额按分存储。
- 账本默认显示当前月，按日期分组展示每日收支小计和账单。
- 账单可编辑、删除；删除需即时反馈并提供短时撤销。

### 7.4 分类

- 支出和收入分别维护分类。
- 两级分类，内置分类开箱即用。
- 用户可新增、改名、排序和隐藏分类；被账单引用后只能归档。
- 语音有独立别名映射，别名不直接增加用户界面复杂度。

### 7.5 统计

- 当前月为默认周期，可前后切换月份。
- 展示支出、收入、结余和较上月变化。
- 每日支出柱状图可点击查看当天明细。
- 分类占比展示金额、笔数和百分比，可下钻到二级分类。
- 展示日均支出和本月最大支出日。

### 7.6 账单搜索

- 账本右上角提供独立搜索入口。
- 未输入条件时展示最近账单；结果按账单时间和创建时间倒序。
- 支持关键词、收支类型、一级/二级分类、开始日期、结束日期、最低金额和最高金额组合筛选。
- 关键词匹配备注、一级分类和二级分类，不把账单正文发送到服务端。
- 条件使用 AND 语义；日期、金额范围非法时给出中文提示，不显示误导性结果。
- 5 笔以上搜索结果仍由可滚动列表承载；点击任一结果进入对应真实账单编辑。
- 搜索完全离线，可读取归档分类下的历史账单，不依赖账号、会员或云备份。
- 详细规则见 [账单搜索规格](./32-ledger-search.md)。

### 7.7 月度回顾与分享

- 统计页对任意月份提供“这个月，过得怎么样？”入口，空月份也进入合理空状态。
- 回顾只使用本机确定性事实：支出、收入、结余、最大一级分类、上月比较、日均、最高支出日、账单数和语音账单数。
- 回顾事实由领域纯函数生成，不让 AI 或服务端补写用户没有的数据。
- 分享必须由用户主动触发，并先展示 App 内预览。
- 默认分享卡使用 4:5 PNG，不展示具体金额、备注、商户、分类名或精确日期；分类占比以区间展示。
- 系统分享面板成功打开后记录匿名事件，但不宣称用户已发送或取消，因为系统 API 不提供可靠结果。
- 详细规则见 [月度回顾与隐私分享卡](./33-monthly-review.md)。

### 7.8 账号与云备份

账号、云备份和微信登录不阻塞免费本地首发。具体外部依赖见 [账号、会员与支付可行性](./25-account-and-payment-feasibility.md)。接入时应先抽象内部 `userId`，不能让会员权益或本机账本依赖微信登录。

- 游客完成第一笔账单后，轻提示“开启云备份”，可永久跳过。
- 后续账号能力启用时，微信可作为候选登录提供方；不做扫码或 Web 登录，也不强制绑定微信。
- 登录后将游客账本合并为首份云端备份。
- 本地账本继续作为主数据源，后续变化自动备份，失败时保留待重试状态。
- 云备份用于备份和换机恢复，不承诺实时多端同步。
- 新设备登录且本地为空时可恢复最近备份；两边都有数据时必须由用户明确选择。
- 退出登录不删除本机账本，只停止后续备份。

### 7.9 数据管理

- 导出版本化 JSON 备份，包含完整账单、分类、排序、语音批次关联、App 版本、导出时间和校验值。
- 导出 UTF-8 BOM CSV 供用户自行查看；CSV 不作为恢复格式，并对公式注入做前置防护。
- 恢复前展示导出时间、App 版本、账单数和分类数；当前账本非空时二次确认。
- 第一版恢复只覆盖本地账本，不合并、不依赖云备份；事务失败不得改动现有数据。
- 删除全部本机数据需要二次确认，明确当前无云备份且删除不可恢复。
- 设置页展示账单数、分类数和最近导出时间。

### 7.10 Android 付款页快捷记账

- 首发仅支持 Android 11（API 30）及以上；用户需手动开启一次无障碍服务并把“声账记账”添加到控制中心。
- 只在用户点击磁贴后读取当前窗口，只允许微信 `com.tencent.mm` 和支付宝 `com.eg.android.AlipayGphone`，不在后台持续监听。
- 优先使用无障碍文本；文本中已有可信实付金额时不截图。文本不足时使用系统允许的一次临时截图和 ML Kit 中文端侧 OCR。
- 自动提取实付金额、时间、收款方/商户，并保守推荐分类；金额、收支类型、一级/二级分类、时间和备注均可修改。用户可以新建一级或二级分类。
- 用户点击“记好这笔”后才写入本地账本；保存后在同一张卡展示 8 秒撤销，不再弹第二个确认框。
- 同一 `captureId` 只能生成一笔账单；来源显示为“屏幕识别”。
- 原始截图不进入相册、不上传、不写入账本/JSON/CSV/日志；临时草稿和截图最长保留 5 分钟后清理。
- 截图失败、OCR 失败、低置信度或非目标页面不能阻断手动记账，确认卡必须允许手动补齐。
- iOS 不允许普通 App 静默读取其他 App 屏幕。后续兼容路线是用户主动运行快捷指令截屏并把图片交给声账确认页；Android 首版不阻塞该适配。
- 详细交互、权限、数据流和验收标准见 [付款页快捷记账规格](./35-payment-screen-capture.md)。

## 8. 发布约束

- 免费首发需要 Apple Developer 和安卓发布账号；微信开放平台资质仅在启用微信登录时另行申请。
- 语音网关服务需要域名、HTTPS、隐私政策和必要备案。
- Apple 个人开发者可以发布免费 App 并使用 Apple 内购；微信登录、微信支付和支付宝 APP 支付按各自主体、认证和审核要求另行启用。
- 上线前完成商标与商店名称复核。
- iOS 与 Android 同步发布；商店构建、隐私清单和权限文案必须一致。

## 9. MVP 完成定义

首发免费版本以本地优先闭环为准：用户可在 iOS 和 Android 真机完成“游客记第一笔 → 一句话多笔 → 撤销/修正 → 查看月度统计 → 搜索账单 → 查看月度回顾并分享脱敏月卡 → JSON 导出与本地恢复”，且无阻断性错误、无账目丢失、无录音或账单正文进入日志。Android 11+ 还要完成“付款成功页 → 磁贴读取 → 修改确认 → 一键入账 → 原地撤销”的真机闭环。

账号登录、云备份、跨设备恢复、微信登录和付费会员属于后续增量能力，不再作为免费本地首发的阻断条件。
