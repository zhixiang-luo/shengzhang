# 分类系统

## 1. 设计目标

分类必须满足三个条件：一眼能找到、语音能理解、长期可维护。界面只展示两级分类，不使用多层树、标签和自定义字段。

| --- | --- |

| 交通 | 公交地铁、打车、加油充电、停车、火车飞机、单车 |
| 购物 | 服饰、日用品、数码、美妆个护、家居 |
| 居住 | 房租、水电燃气、物业、维修 |
| 娱乐 | 电影演出、游戏、会员订阅、旅游、其他 |
| 医疗健康 | 门诊、药品、体检、保险 |
| 学习教育 | 书籍、课程、考试、文具 |
| 人情礼物 | 红包、礼物、请客、孝敬 |
| 通讯网络 | 话费、宽带、云服务 |

| 其他 | 其他 |

## 3. 内置收入分类

工资、奖金、兼职、理财收益、红包、退款、报销、其他。

收入默认只有一级分类。用户可以为收入新增二级分类，但界面不主动展开，保持记录速度。

## 4. 语音别名映射

别名由服务端可配置，客户端展示标准分类名称。

| 常见表达 | 映射 |
| --- | --- |
| 早饭、早点、包子 | 餐饮 / 早餐 |
| 中饭、午餐、盒饭 | 餐饮 / 午餐 |
| 晚饭、夜宵、烧烤 | 餐饮 / 晚餐 |
| 咖啡、拿铁、奶茶、喜茶 | 餐饮 / 咖啡奶茶 |
| 地铁、公交、通勤卡 | 交通 / 公交地铁 |
| 滴滴、出租、网约车 | 交通 / 打车 |
| 房租、押金、租金 | 居住 / 房租 |
| 水费、电费、燃气费 | 居住 / 水电燃气 |
| 爱奇艺、优酷、会员 | 娱乐 / 会员订阅 |
| 药、医院、挂号 | 医疗健康 / 门诊或药品 |
| 红包、礼金 | 依上下文判断：发出为支出，收到为收入 |
| 退款、退钱 | 收入 / 退款 |
| 报销到账 | 收入 / 报销 |

别名冲突时按以下优先级：金额与动词语义 > 收支类型 > 用户历史偏好 > 默认分类。

## 5. 分类推荐

手动记账的分类区展示：

1. 最近使用的 3 个一级分类。
2. 当前时段的高频分类。
3. 用户过去 30 天使用最多的分类。

语音解析只发送当前启用的分类名称，不发送历史账单。服务端返回分类路径或标准名称，客户端映射成 ID。

## 6. 编辑规则

- 内置分类可改名、排序和隐藏，不建议删除。
- 自定义分类最多 20 个一级分类；每级最多 20 个二级分类。
- 被账单引用的分类只能归档，历史账单继续显示原名快照。
- 隐藏分类不出现在新增账单的选择器，但统计仍保留。
- 分类名称去除首尾空格后长度为 1–12 个字符。
- 同一父级下不允许重名；大小写和全半角视为相同。

## 7. 图标与颜色

- 一级分类使用同一线性图标体系，保留固定识别度。
- 颜色仅用于图表和少量图标背景，不形成彩虹式列表。
- 分类切换不得改变全局主色。
