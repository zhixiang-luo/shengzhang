# 声账官网

日期：2026-10-22
状态：首版已完成，等待产品评审与域名发布

## 1. 目标

官网服务于三个目标，按优先级排列：

1. 在 10 秒内让第一次访问的人理解“声账是什么、解决什么问题”。
2. 提供可信、可操作的产品下载与 GitHub 入口。
3. 通过真实产品界面、质量数据和隐私边界建立信任，而不依赖夸张营销文案。

官网不承担在线记账、账号注册、支付或客服表单。首版是纯静态页面，避免在没有业务必要时引入数据库、登录和额外攻击面。

## 2. 当前实现

源码目录：`deploy/site/`

| 文件 | 责任 |
| --- | --- |
| `index.html` | 页面语义结构、产品文案、SEO 与软件结构化数据 |
| `styles.css` | 品牌视觉、响应式布局、动画与无障碍降级 |
| `app.js` | 首屏语音演示、滚动揭示、导航、产品界面切换与轻量交互 |
| `assets/` | 官网使用的品牌 SVG、品牌分享图和真实产品截图 |

首版页面顺序：

1. 首屏：品牌主张、真实语音示例、Android 内测入口与 GitHub 入口；
2. 为什么做：对比传统记账步骤与一句话记账；
3. 怎么记：切换语音入账、月度统计和手动兜底真实界面；
4. 能力：一句话多笔、8 秒撤销、本地优先和月度理解；
5. 隐私：语音、结构化与本地存储的数据边界；
6. 质量：200 条语音基线与 P95 耗时；
7. 独立开发者与开源说明；
8. Android 内测下载、GitHub Releases 与 iOS 后续计划。

## 3. 视觉方向

官网延续 App 的“温暖、克制、有一点灵动”：

- 米白纸张底色搭配墨色正文；
- 腮红 `#A45358` 作为主行动色，鼠尾草绿表达本地与安全；
- 宋体标题负责产品气质，苹方正文保证阅读效率；
- 小猪品牌角色只做可信、亲近的品牌锚点，不使用商业化表情或夸张拟人；
- 首屏用“声波进入账本”的动态装置作为记忆点，不使用通用 SaaS 渐变卡片。

所有新增颜色、间距和圆角优先沿用 `design/tokens/`。官网允许为了大屏叙事增加字号与留白，但不改变 App 内的视觉令牌基线。

## 4. 动效与降级

当前动效包括：

- 首屏文字错峰进入与标题手绘下划线；
- 语音波形、实时转写和两笔账单依次出现；
- 滚动进入时的元素揭示；
- 鼠标跟随光晕、设备轻微空间倾斜；
- 产品界面切换与下载卡片波形。

当系统设置 `prefers-reduced-motion: reduce` 时，所有动画缩短到几乎不移动，内容直接显示。交互动效不得承载唯一信息。

## 5. 链接策略

当前下载入口：

- Android 内测：官网直接下载 `/downloads/shengzhang-android-preview.apk`；
- 全量版本索引：GitHub Releases；
- 源码：`https://github.com/zhixiang-luo/shengzhang`。

官网直接下载不要求 Expo 账户，适合把测试包发给没有 Expo 账号的用户。正式发布后，首屏主按钮应优先指向 GitHub Release 的稳定 APK 或已上架商店；每次替换 APK 都要同步版本号、文件大小和 SHA-256。iOS 未上架前不得展示可点击的 App Store 下载按钮。

2026-10-22 已从匿名请求复验 GitHub 仓库与 Releases 可访问。`v0.1.3-preview.1` Release 尚未创建，当前官网下载是唯一公开发布的 `0.1.3` 入口。

## 6. 部署

生产静态目录为 `/opt/shengzhang/site`。Nginx 配置见 `deploy/nginx/shengzhang-test.conf`。

本地预览：

```bash
python3 -m http.server 4174 -d deploy/site
```

2026-10-21 已部署到现有 ECS，临时公网入口为 `http://8.152.201.57/`。首页、CSS、JavaScript、产品截图与原有 `/health` 均从公网返回 `200`。

该 IP 入口只用于备案完成前的临时访问，不配置表单、登录或支付，也不应作为长期推广地址。中国大陆服务器绑定正式域名前，必须完成 ICP 备案；备案通过并配置 HTTPS 后，再替换当前测试入口。

Android 内测包保存在服务器 `/opt/shengzhang/site/downloads/shengzhang-android-preview.apk`，官网直接提供下载，不依赖 Expo 登录。当前版本为 `0.1.3`，文件大小 109,854,465 字节，SHA-256 为 `89db26c0d314dde5800368c947aa74d501bfa42d329de90f465f5377366dfecf`。该版本首次包含 EAS OTA 客户端；已安装 `0.1.2` 的设备需要覆盖安装一次。

2026-10-22 21:10（Asia/Shanghai）已完成官网替换。首页下载链接使用 `?v=0.1.3`，公网响应 `200` 且 `Content-Length` 为 109,854,465 字节；服务器端 SHA-256 与构建产物一致。旧 `0.1.2` 保留在 `/opt/shengzhang/releases/shengzhang-0.1.2-preview.apk`。

首版已检查：

- `1440 × 1000`、`768 × 1024`、`390 × 844`、`375 × 812` 四种视口；
- 页面无横向滚动；
- 移动端菜单可打开、关闭，并支持 `Escape` 关闭；

- 所有图片与本地资源成功加载；
- 页面自身无控制台错误；
- 减少动态效果设置可用；
- 下载、GitHub 与 Releases 链接均有明确目标。
