# 快捷记账重做实施计划

日期：2026-11-13。用户已确认实施。执行方式：当前 feature 分支内顺序实现，保留前次审计文档；实现由主 Agent 顺序完成；收尾按 requesting-code-review 技能使用一个只读独立审查 Agent，主 Agent 集成修复并最终验收。

目标：磁贴按需截图后回到声账，展示无滚动的简洁确认卡，保存按钮始终可见；按需修改后单次确认入账。准确性优先，支持可替换的云端视觉识别与本地降级。

本次用户修订优先于 36 号提案：不实现跨 App 透明小窗口，不申请悬浮窗权限；小卡在声账内部显示。默认不展开完整编辑表单，二级分类不自动取第一个。

## 约束

- 金额为正整数分或未知；余额、优惠、原价不是实付，非成功交易不能自动当消费。
- 未识别显示“待补金额”；多金额冲突先核对。分类推荐可以修改，商品没有页面依据时显示商户。
- 本地时间使用采集时刻做固定默认，并明确标注来源；不让晚到识别覆盖用户编辑。
- 云端只在用户选择后调用；密钥仅服务端；图片与正文不进日志或长期存储；失败保留草稿。
- 复用 screen 来源、captureId 幂等与 8 秒撤销。原生能力变化需要新 APK，不冒充 OTA 已生效。
