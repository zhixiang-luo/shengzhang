# 数据与隐私设计

## 1. 数据分类

| 数据 | 存储位置 | 是否上传 | 保留策略 |
| --- | --- | --- | --- |
| 账单、分类、设置 | 本机 SQLite | 登录后进入加密备份 | 用户删除或退出前持续保留 |
| 语音录音 | 设备内存/临时请求 | 仅上传用于识别 | 请求结束立即丢弃，不落盘、不保留 |
| 语音转写文本 | 服务端内存 | 是 | 请求结束立即丢弃，不进日志 |
| 微信用户标识 | 服务端账号库 | 是 | 账号存在期间保留 |
| 匿名安装 ID | 本机与服务端 | 是 | 用于额度校验，可重置或随卸载失效 |
| 匿名产品事件 | 服务端私有 JSONL | 是 | 功能名、平台、版本和账单条数；不含账目正文 |
| 崩溃与性能事件 | 第三方或自建服务 | 最小化事件 | 不含账单、分类名称、录音和转写 |

## 2. 本地优先

- 游客与登录用户的账本都以本机 SQLite 为当前数据源。
- 手动记账、统计、分类和导出离线可用。
- 本地数据库放在应用沙盒内，金额使用整数，记录使用 UUID。
- 默认排除系统自动云备份，避免在用户不知情时把账本同步到 iCloud/Google。
- 用户通过 JSON 完整备份主动迁移或恢复。

## 3. 语音隐私

- 首次使用语音前说明：录音会上传至云端转写，并用于生成账单。
- 不使用语音训练模型，不保留原始音频。
- 音频只在处理请求期间存在于内存和临时传输层。
- 服务商必须关闭默认数据留存或选择零留存配置。
- 客户端上传前不附带历史账单，只附带当前分类名称、时区、语言和安装标识。
- 若用户拒绝麦克风或云端识别，仍可完整使用手动记账。

## 4. 微信登录

- 明确说明登录目的：云备份、换机恢复、账号安全。
- 仅请求完成登录所需的最小授权范围。
- 不在界面展示不必要的微信资料。
- 不在客户端保存 AppSecret。
- 用户退出登录后停止云备份；本机账本保留。
- 提供账号注销和数据删除说明，正式上线前补齐服务端删除流程。

## 5. 云备份

- 备份按账号隔离，使用服务端加密存储。
- 备份对象禁止公开访问。
- 下载时验证当前登录态和备份归属。
- 备份包含账单、分类和必要设置，不包含录音和转写文本。
- 退出登录不会自动删除云端备份；删除账号或删除数据时需明确选择服务器数据。
- 备份失败日志只记录错误码、请求 ID、大小和耗时。

## 6. 日志与监控

禁止进入日志：

- 账单金额、备注、分类名称。
- 语音转写文本和原始音频。
- 微信 access token、refresh token、AppSecret。
- 用户昵称、头像 URL、openid/unionid 的明文组合。

允许记录：

- 随机请求 ID。
- 状态码、错误码、耗时、设备平台和 App 版本。
- 匿名安装标识的不可逆哈希。

产品统计的事件字典、用户开关和报告口径见 [隐私优先的产品统计](./29-privacy-first-analytics.md)。

## 7. 导出与删除

### 导出

- JSON：完整账本、分类、设置和 schema 版本，用于恢复。
- CSV：账单字段平铺，便于用户自行查看。
- 导出前验证本机数据库完整，导出文件使用当前时间命名。

### 删除

- `删除全部数据` 需要二次确认，并明确是否同时删除云端备份。
- 删除本机后立即关闭自动备份，避免空账本覆盖云端。
- 删除成功后回到游客空账本。

## 8. 权限文案

麦克风：

> 声账需要使用麦克风听取你的账单内容。录音仅用于本次云端识别，完成后立即丢弃。

通知（若后续加入）：

> 开启提醒，在你选择的时间轻提示记一笔。可随时关闭。

微信：

> 微信登录仅用于开启云备份和换机恢复。登录后，账本仍以本机为准。

## 9. 上线前隐私检查

- 更新 App Store 隐私清单和 Google Play Data Safety。
- 隐私政策列出 ASR、大模型、云存储和崩溃监控供应商。
- 落实国内个人信息保护要求与适用备案。
- 所有第三方 SDK 在隐私同意前不初始化或采集数据。
- 测试包和正式包不包含调试日志、测试密钥或模拟账单。
