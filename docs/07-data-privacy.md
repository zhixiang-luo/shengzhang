# 数据与隐私设计

## 1. 数据分类

| 数据 | 存储位置 | 是否上传 | 保留策略 |
| --- | --- | --- | --- |
| 账单、分类、设置 | 本机 SQLite | 登录后进入加密备份 | 用户删除或退出前持续保留 |
| 语音录音 | 设备内存/临时请求 | 仅上传用于识别 | 请求结束立即丢弃，不落盘、不保留 |
| 语音转写文本 | 服务端内存 | 是 | 请求结束立即丢弃，不进日志 |
| 本次账单截图 | 原生内存；分享副本为私有短期草稿 | 快捷功能首次同意后直接云端，仅当前图 | 任务五分钟失效；分享副本保存/取消/活跃到期或下次访问清理 |
| 微信用户标识 | 服务端账号库 | 是 | 账号存在期间保留 |
| 匿名安装 ID | 本机与服务端 | 是 | 用于额度校验，可重置或随卸载失效 |
| 匿名产品事件 | 服务端私有 JSONL | 是 | 功能名、平台、版本和账单条数；不含账目正文 |
| 用户主动提交的反馈 | 服务端私有反馈文件 | 是 | 反馈正文、反馈类型和用户选填的联系方式；默认保留 180 天 |
| 崩溃与性能事件 | 第三方或自建服务 | 最小化事件 | 不含账单、分类名称、录音和转写 |

## 2. 本地优先

- 游客与登录用户的账本都以本机 SQLite 为当前数据源。
- 手动记账、统计、分类和导出离线可用。
- 本地数据库放在应用沙盒内，金额使用整数，记录使用 UUID。
- 默认排除系统自动云备份，避免在用户不知情时把账本同步到 iCloud/Google。
- 用户通过 JSON 完整备份主动迁移或恢复。

## 3. 语音隐私

- 首次使用语音前说明：录音会上传至云端转写，并用于生成账单。
- 不使用语音训练模型，不保留原始音频。
- 音频只在处理请求期间存在于内存和临时传输层。
- 服务商必须关闭默认数据留存或选择零留存配置。
- 客户端上传前不附带历史账单，只附带当前分类名称、时区、语言和安装标识。
- 若用户拒绝麦克风或云端识别，仍可完整使用手动记账。

## 4. 微信登录

- 明确说明登录目的：云备份、换机恢复、账号安全。
- 仅请求完成登录所需的最小授权范围。
- 不在界面展示不必要的微信资料。
- 不在客户端保存 AppSecret。
- 用户退出登录后停止云备份；本机账本保留。
- 提供账号注销和数据删除说明，正式上线前补齐服务端删除流程。

## 5. 云备份

- 备份按账号隔离，使用服务端加密存储。
- 备份对象禁止公开访问。
- 下载时验证当前登录态和备份归属。
- 备份包含账单、分类和必要设置，不包含录音和转写文本。
- 退出登录不会自动删除云端备份；删除账号或删除数据时需明确选择服务器数据。
- 备份失败日志只记录错误码、请求 ID、大小和耗时。

## 6. 日志与监控

禁止进入日志：

- 账单金额、备注、分类名称。
- 语音转写文本和原始音频。
- 账单截图、base64、OCR 正文、视觉模型输出和金额证据。
- 微信 access token、refresh token、AppSecret。
- 用户昵称、头像 URL、openid/unionid 的明文组合。

允许记录：

- 随机请求 ID。
- 状态码、错误码、耗时、设备平台和 App 版本。
- 匿名安装标识的不可逆哈希。

产品统计的事件字典、用户开关和报告口径见 [隐私优先的产品统计](./29-privacy-first-analytics.md)。

## 7. 月度回顾与分享卡

- 月度回顾只读取本机账本，不上传历史账单，不调用模型生成事实。
- 分享必须由用户主动打开预览并再次触发；App 不会自动发图或自动选择分享目标。
- 默认分享卡不包含具体金额、备注、商户、分类名称和精确日期。
- 分享卡中的分类占比是区间，趋势只表达方向；语音笔数是范围有限的匿名使用事实，不包含转写。
- PNG 只写入应用临时目录，分享调用返回后立即清理。
- 系统分享面板打开后的去向由操作系统和其他 App 处理，声账不能保证对方删除或撤回。

完整内容、导出尺寸和统计边界见 [月度回顾与隐私分享卡](./33-monthly-review.md)。

## 8. 导出与删除

### 导出

- JSON：完整账本、分类、设置和 schema 版本，用于恢复；包含导出时间、App 版本、数量与完整性校验值。
- CSV：账单字段平铺，带 UTF-8 BOM，便于中文 Excel/WPS 查看，不作为恢复输入。
- 导出前验证本机数据库完整，导出文件使用当前时间命名。
- CSV 对以 `=`, `+`, `-`, `@`, Tab 或换行开头的字段做公式注入防护。
- 导出不包含 API Key、Token、原始录音、匿名安装 ID 或服务端日志。

### 删除

- `清空本机账本` 需要二次确认，并明确当前没有云备份、删除不可恢复。
- 删除在 SQLite 事务中执行；失败时整体回滚。
- 删除成功后回到游客空账本。
- 详细数据格式和恢复规则见 [本地数据备份与恢复](./31-local-data-portability.md)。

## 10. 改进与反馈

- 反馈不要求登录，联系方式选填；不填写时按匿名反馈处理。
- 自动诊断信息只包含 App 版本、平台、系统版本、系统语言、当前页面和可选错误码/请求 ID。
- 关闭诊断信息后，客户端不发送 `diagnostics` 字段。
- 不自动附带金额、分类、备注、录音、语音转写或账单截图。
- 反馈正文和联系方式不进入匿名产品统计，也不写入普通 API 日志。
- 服务端只保存匿名安装 ID 的加盐哈希，不保存原始安装 ID。
- 生产反馈文件位于 `/opt/shengzhang/shared/reports/.feedback`，默认保留 180 天。
- 每日运营简报只展示反馈总数和类型分布；具体反馈只能通过服务器私有命令读取。

## 11. 上线前隐私检查

- 更新 App Store 隐私清单和 Google Play Data Safety。
- 隐私政策列出 ASR、大模型、云存储和崩溃监控供应商。
- 落实国内个人信息保护要求与适用备案。
- 所有第三方 SDK 在隐私同意前不初始化或采集数据。
- 测试包和正式包不包含调试日志、测试密钥或模拟账单。

## 12. 付款页截图与默认云端视觉（0.3.3）

无障碍只观察窗口来源，不后台遍历正文。用户主动点击磁贴或已分配的系统动作才截取当前微信/支付宝；服务内存处理图片，并用 TYPE_ACCESSIBILITY_OVERLAY 在原页面确认。不申请 SYSTEM_ALERT_WINDOW，不打开主 App 采集其他页面。主动分享只读取所选单张 content URI，不读取相册全集。系统截图原图由用户管理。0.3.3 删除边缘按钮；阶段诊断仅保存固定错误码、来源种类及截图尺寸/字节，不保存图片、识别正文、金额、商户或数据库路径。

任务逻辑有效期五分钟，关闭/切其他 App/锁屏/撤权/到期取消请求和旧回调。原生截图不落图片文件；分享副本在应用缓存生成、同锁发布到 noBackupFilesDir，AtomicFile 写 metadata，保存/取消/活跃到期或下次原生访问清理。进程被终止后不保证第五分钟准点物理删除。

首次启用快捷功能说明本次与后续主动截图直接发送云端；同意一次后不先做本地 OCR，也不反复确认上传。保持已明确关闭选择，开关撤回时立即拦截待上传任务/取消在途请求；重新开启不复活旧图。分享入口无既有授权时展示实际图及说明，拒绝可手填。
