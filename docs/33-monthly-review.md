# 月度回顾与隐私分享卡

日期：2026-11-05
状态：`0.2.0` 已实现，自动化与双端导出通过，真机待验收
上位文档：[可信语音与月末回顾](./22-voice-trust-and-monthly-review.md)

## 1. 目标

月度回顾只回答一个低负担问题：

> 这个月，我的钱大概花在了哪里？

首版不使用 AI 生成事实，不依赖网络、账号、会员、支付或云备份。所有数字来自本机 SQLite，规则集中在 `packages/domain/src/monthly-review.ts`，页面、模板和后端都不能各自重算一套口径。

## 2. 确定事实

回顾包含：

- 支出、收入、结余；
- 账单数、支出笔数、收入笔数和语音账单笔数；
- 最大一级支出分类、金额和四舍五入后的占比；
- 与上月支出比较的方向和百分比；
- 日均支出；
- 支出最高日；金额并列时取较晚日期；
- 一句由固定规则拼接的事实型文案。

计算边界：

- 金额始终是正整数分 `amountMinor`；
- 当前月份按已经过去的天数计算日均，最少按 1 天；
- 历史月份按该月完整天数计算日均；
- 上月没有支出时标记 `no_baseline`，不编造百分比；
- 空月份返回 `这个月还没有账单。`，不生成分类、趋势或消费评价；
- 回顾账单必须属于请求月份，非法月份、日期和金额会拒绝计算。

## 3. 用户路径

```text
统计页
  -> 查看任意月份
  -> 这个月，过得怎么样？
  -> 月度回顾页
  -> 查看事实、分类与语音记录
  -> 主动打开分享预览
  -> 生成 1080×1350 PNG
  -> 调起系统分享面板
```

- 统计页无论当月是否有账单都显示回顾入口。
- 无数据月份进入回顾页后显示空状态和“记下第一笔”，仍可返回统计。
- 回顾页显示真实分类名称和最高支出日，因为这些内容只在本机页面展示。
- 分享必须由用户主动点击；默认只展示看过预览的脱敏卡片。

## 4. 分享卡隐私契约

分享卡固定为 4:5，导出 PNG 为 `1080×1350`。默认展示：

- 月份；
- “这个月，我说一句就记下了 N 笔。”；
- 最大一级分类的占比区间；
- 较上月变多、变少、持平或刚开始的趋势文案；
- 非零语音账单笔数；
- 品牌主张和 `我也来记一句`。

默认不展示：

- 具体支出、收入、结余或分类金额；
- 备注和商户；
- 一级、二级分类名称；
- 精确账单日期；
- 转写、录音或安装标识。

分类占比使用 `0%–25%`、`25%–50%`、`50%–75%`、`75%–100%` 四档，不展示精确占比。当前版本不提供“公开金额”的开关；未来如增加，必须保持默认关闭并重新做预览、埋点和验收。

## 5. 实现边界

- 聚合：`packages/domain/src/monthly-review.ts`；
- 数据读取：`apps/mobile/src/features/review/useMonthlyReview.ts`；
- 分享文案：`apps/mobile/src/features/review/shareCard.ts`；
- 卡片渲染：`apps/mobile/src/components/ShareReviewCard.tsx`；
- 页面与系统分享：`apps/mobile/src/app/review.tsx`；
- 原生截图：`react-native-view-shot@6.1.1`；
- 系统分享：`expo-sharing`。

PNG 写入临时文件，系统分享面板返回后调用 `releaseCapture` 清理。分享过程中不读取网络，也不上传图片；图片是否被发送由用户在系统分享面板中决定。

## 6. 匿名统计

| 事件 | 触发时机 | 属性 |
| --- | --- | --- |
| `monthly_review_opened` | 打开回顾页 | 平台、App 版本 |
| `monthly_review_previewed` | 打开脱敏分享预览 | 平台、App 版本 |
| `monthly_review_share_opened` | 成功生成 PNG 并调起系统分享面板 | 平台、App 版本 |
| `monthly_review_share_failed` | 设备不支持分享、截图或分享调用失败 | 固定原因 `share_failed` |

不上报金额、分类名、趋势值、笔数、日期、图片内容或用户选择的分享目标。

`expo-sharing` 不提供可靠的“已发送”或“用户取消”结果，因此：

- `monthly_review_share_opened` 只表示系统分享面板成功打开；
- 不统计完成发送；
- 不虚构取消事件；
- 分享按钮被用户取消后，不以错误事件上报。
