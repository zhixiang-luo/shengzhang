# 付款页快捷记账规格

> 当前实现：0.3.3(37) 内测线，已在微信、支付宝真机闭环，最新变更、构建与上线清单见 [44](./44-quick-accounting-device-verification.md)；本轮反馈背景见 [42](./42-quick-accounting-device-feedback.md)。2026-11-13 用户批准云端直接识别、无障碍原页面浮层、一次确认入账，取代 0.3.1 的应用内确认/本地优先/保存后撤销路线。决策见 [39](./39-cloud-overlay-and-shortcuts.md)，平台差异见 [40](./40-shortcut-platform-support.md)，上一版构建见 [41](./41-cloud-overlay-validation.md)。历史审计与旧包证据分别保留在 [36](./36-quick-accounting-redesign.md)、[38](./38-quick-accounting-validation.md)。

## 1. 产品行为

在微信或支付宝单笔付款详情页主动触发声账，无需打开主 App。在原页面上方核对金额、商品或商户、时间和分类，有误时点字段修改，再点一次“确定收好了”。成功写入现有账本并关闭浮层；失败保留内容，允许重试。快捷记账没有第二次“收好”或八秒撤销；删除到账本操作，语音既有撤销不变。

- Android 11+（API 30），必须安装含新原生模块的 APK。Expo Go/Web 不支持真实截图。
- 采用用户已授权的 `AccessibilityService` 和 `TYPE_ACCESSIBILITY_OVERLAY`，不申请 `SYSTEM_ALERT_WINDOW`，不以透明主 Activity 模拟确认卡。
- 不后台采集正文、监听支付通知或读取剪贴板；无障碍事件仅用于识别窗口来源。只有主动触发才截图。
- 银行不在自动采集白名单；可正常截图的银行单笔图可尝试主动分享，安全页面不能绕过。
- iOS 本轮只调研，没有实现图片 App Intent 或跨 App 浮层。厂商背部/侧键手势以机型设置为准。

## 2. 入口与采集

```text
微信/支付宝详情 → 磁贴/已分配的系统动作
→ 收起控制中心、隐藏自身窗口 → 校验来源窗口 → 截图
→ 原页面显示识别中卡 → 直接云端视觉 → 编辑核对
→ 确定收好了 → 同一个 SQLite 账本 → 提示并收起
```

系统磁贴、系统无障碍按钮和独立快捷 Activity 共用一次任务。设置只保留无障碍与磁贴两步、简短机型手势说明；删除边缘按钮及旧偏好、删除“添加快捷动作”按钮。磁贴状态由系统确认和生命周期维护，未知不假勾，回前台/控制中心收起时刷新。独立 Activity 立即结束，等待下面付款页恢复后采集，不打开 React 主页面。桌面上点击时若下面是桌面则拒绝，不使用旧付款页面。固定快捷方式不代表所有厂商手势都能选择该动作。

截图前及成功回调后复核同一包名、windowId 和窗口版本。窗口改变、切到其他 App、锁屏、取消、关闭云端、新任务、服务销毁或到期均使旧任务失效。微信缺少文字节点时仍尝试以活动/聚焦窗口和近期窗口事件确认来源，不因无法读取正文跳过截图。实际微信和控制中心表现需真机验证。

用户也可主动截图 → 系统分享“声账 · 记一笔” → 应用内同样简卡。只接收单张 `ACTION_SEND image/*` 的 `content://` 图片，不读取整个相册，不要求无障碍。导入上限 8 MB、边长 10000、4000 万像素；解码前限制并缩采样。返回/取消后不再拉起页面。

## 3. 紧凑确认卡

| 字段 | 展示与修改 |
| --- | --- |
| 金额 | 大字号；未知为“待补金额”，保留空值；金额持久化为整数分 |
| 内容 | 自动结果的商品/商户最多40字；应用内手填40字、原生编辑最多120字，主卡单行省略；不编造购买物品 |
| 分类 | 复用已有分类，一个入口，编辑时选择收支及分类；无识别建议时优先同类型有效“其他”根分类，不自动选子分类 |
| 时间 | 优先带依据的交易时间，否则固定本次采集时刻并标“默认当前时间” |
| 主按钮 | “确定收好了”；识别中、金额缺失、无有效分类、明确阻断或保存中不可点击 |

默认卡无滚动。金额/内容编辑自动聚焦并等待窗口焦点后请求原生键盘；分类/日期直接进入选择器，分类列表可单独滚动。原生浮层宽约 320dp；应用内分享卡最多 360。重新识别只填未编辑字段，保护人工选择的分类及其收支类型。失败/待付款、退款、转账、外币等 `blockingReason` 不可通过手工补金额绕过，转手动入口处理。

## 4. 云端直接识别与授权

本路线不执行本地 OCR/文本解析，不用本地猜测决定是否调用模型，也不用旧本地结果覆盖云端空字段。历史领域解析和 ML Kit 兼容接口保留，但不参与新快捷流程。

首次启用快捷记账说明本次及后续主动截图上云，同意一次后每次直接识别；无既有授权的单张分享先展示实际图片及说明。明确关闭的用户不被静默重新开启，仍可手动/语音记账。JS 与原生授权同步；关闭立即取消在途请求，准备期间 off→on 不复活旧请求，前台配置刷新不会覆盖关闭选择。

- 手机只调声账 `/v1/screen-bill/parse`；供应商 Key 只在服务端。
- 发送压缩当前图、采集时间、时区、启用分类、captureId 与安装额度标识，不发送历史账本。安装标识不转给供应商。
- 图片最长边 1600、JPEG、最多 2 MB。原生截图仅在内存处理；分享图片副本短期保存在应用私有目录。
- 服务端复核单笔、成功状态、人民币、金额数字/符号及原文证据、同收支分类及带时区交易时间；支持无单位顶部小数和分行金额，不再复用旧OCR打分器；明确状态标签需为成功，外币ISO代码和标准中文币种名不可被CNY枚举覆盖，返回严格 schema。JSON 格式不能代替业务校验。缺金额为 null，失败不伪造 0.00，不自动退回不可靠本地识别。
- 当前线上视觉模型为 DeepSeek Flash（`https://api.deepseek.com`）；官方千问 `qwen3-vl-plus` 非思考/JSON Object 适配保留为备选，实际启用取决于服务端专用凭证。切换证据见 [19](./19-ai-providers.md)、[38](./38-quick-accounting-validation.md)。
- 截图未自动脱敏，可能含姓名、余额、卡号等；可先遮盖无关信息再主动分享。声账网关请求内存处理、不落图、不记正文，供应商按条款审核/保留，不能宣传全链路零留存，见 [07](./07-data-privacy.md)。

## 5. 原生与账本

| 文件 | 职责 |
| --- | --- |
| BillCaptureAccessibilityService | 任务/窗口校验、截图、取消与系统按钮 |
| BillOverlayController / OverlayBillRules | 服务拥有的浮层、编辑/阻断规则、金额/时间校验 |
| OverlayCloudClient | 内存图到声账网关，响应校验/超时/取消 |
| OverlayConfiguration | 私有配置与授权；实际同库路径、HTTPS 地址校验 |
| OverlayLedger | 打开既有 SQLite v3，分类复核、事务写入及幂等 |
| CaptureShortcutActivity / BillCaptureTileService | 独立动作、系统磁贴入口 |
| ShareBillActivity / PendingCaptureStore | 单张分享、AtomicFile 草稿发布/过期清理 |
| ScreenCaptureModule | Expo 配置/状态/设置/图片导出兼容桥 |

主 App 完成迁移后通过实际 `db.$client.databasePath` 配置原生。原生仅允许本应用 `filesDir/SQLite/shengzhang.db`，不创建第二份库，不改旧迁移；验证 user_version=3、外键、busy timeout 和 rollback journal（不要把 WAL 与 expo-sqlite 混用，跨 SQLite 实现的 checkpoint 可能触发 SQLITE_IOERR）。同一事务写 `source=screen`、有效根/子分类、UTC 时间、金额及 `backup_state=pending`。captureId 为主键；重复保存不改已有内容，已删 id 不复活。App 回前台时重新读账本/统计、搜索、月回顾，展示应用外新增记录。

任务五分钟失效，不允许过期保存。分享副本在保存、取消、替换、活跃到期或下次原生访问时清理；进程不运行时不承诺第五分钟准点物理删除。系统截图原图由用户管理。原图、正文、证据不进入最终账单、JSON 或 CSV。

## 6. 失败与验证

| 情况 | 行为 |
| --- | --- |
| 服务未连接/旧包缺能力 | 说明设置或安装新版，不假装可识别 |
| 窗口不支持/安全限制/截图失败 | 明确失败，重新触发或手动/语音 |
| 网络/额度/供应商失败 | 保留可编辑空草稿，可重试；不猜金额 |
| 金额未知 | 待补金额，补齐前禁保存 |
| 明确失败/待付/退款/转账/外币 | 强阻断，手动另行处理 |
| 保存失败 | 保留编辑，允许再点，不重复写入 |

自动化、真实 RNWeb 分享组件、Kotlin API 编译、EAS 完整原生构建、APK 签名和真机验收分别记录在 [42](./42-quick-accounting-device-feedback.md)，0.3.2历史保留41号，互不替代。0.3.3 需要新 APK/runtime；先用户安装测试，通过后再决定公开发布。官网/CDN/更新策略仍为 0.2.1，不发旧 runtime OTA。
