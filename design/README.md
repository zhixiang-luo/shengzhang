# 声账视觉系统

## 方向

**温暖克制，像一张有触感的纸和一枚安静的小猪印章。**

视觉不追求卡通乐园，也不复制传统金融产品的冷蓝和密集卡片。页面以奶油纸色留出呼吸感，用偏暖的墨色建立秩序，以小猪腮红和声波弧线作为唯一强记忆点。小猪只在需要情绪反馈时出现，不成为背景贴图。

## 关键词

- 安静、轻盈、可信
- 奶油纸、墨色、腮红
- 大留白、少边框、软圆角
- 数字醒目、说明克制
- 有生命感但不幼稚

## 使用规则

- 一屏最多一个腮红主按钮；其他操作用墨色文字或浅色底。
- 账单金额使用等宽数字特性，列表金额右对齐。
- 不把每个模块都装进白色卡片；优先通过留白和分隔线组织。
- 小猪插图只出现在启动、空状态、成功反馈和引导中。
- 图表不追求彩虹分类，主要使用腮红、鼠尾草绿、沙金和暖灰。
- 动效只服务于状态变化，不做装饰性循环动画。
- 首版不做深色模式，但必须验证系统深色外观下的可读性。
