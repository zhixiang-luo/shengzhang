# Moodboard

## 一句话

像把一张柔软的纸放进钱包：没有金融 App 的压迫感，也没有儿童贴纸的喧闹。

## 材质

- 主体接近未漂白的奶油纸，而不是纯白。
- 账单块之间用空气和极淡分隔线，不用厚重阴影堆出层级。
- 圆角偏大但不过分胶囊化，形成温和、可触碰的边界。
- 小猪图形像压印或印章，边缘干净，避免高光和 3D 拟物。

## 排版

- 品牌和情绪标题使用宋体气质的字形，增加安静感。
- 正文使用苹方/系统中文字体，保证双端可读。
- 金额是页面主角，使用清晰、等宽的西文数字。
- 标题与数字形成“编辑感排版”，正文保持克制的小字号。

## 色彩

- 奶油白 `#FAF7F0`：主背景。
- 暖墨 `#292624`：正文与主图标。
- 小猪腮红 `#E89A96`：主行动与成功状态。
- 深莓红 `#9D5657`：腮红的可读文字版本。
- 鼠尾草 `#9EAD98`：收入、平衡与辅助图表。
- 沙金 `#E1BD7B`：提醒与第三组图表。

不使用紫蓝渐变、霓虹色、纯黑大背景和过多高饱和分类色。

## 图形

- 主图形语汇：圆弧、声波、柔软小猪轮廓。
- 声波不是科技频谱，而是三道呼吸感的弧线。
- 分类图标采用细线、圆端点和统一视觉重量。
- 空状态可用小猪侧影和一句轻松但不说教的文案。

## 动效

- 页面切换 180–240ms，使用轻微位移和透明度。
- 录音波形只随真实音量变化，不使用循环假波形。
- 入账成功用一次短促的腮红扩散，不使用撒花或金币。
- 尊重系统减少动态效果设置。

## 避免

- 不使用 emoji 作为正式品牌资产。
- 不把“小猪”做成粉色渐变、玻璃拟态或 3D 盲盒。
- 不堆叠 dashboard 卡片、渐变按钮和通用 SaaS 图标。
- 不用过度可爱的文案削弱账单数据的可信度。
