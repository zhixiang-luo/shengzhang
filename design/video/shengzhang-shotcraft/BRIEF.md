# 声账宣传片 · 产品与执行简报

## 创作模式

自主自由创作。用户已授权“自由发挥”，因此由 Agent 完成产品简报、视觉方向、镜头映射、分镜和制作放行，不在中间阶段等待确认。

## 产品简报

- 产品：声账
- 一句话：语音优先的个人记账应用
- 品牌主张：说一句，就记好。
- 目标用户：18–35 岁学生和年轻职场人
- 核心任务：付款后，用一句话在几秒内完成一至多笔记账
- 关键能力：实时转写、自动结构化、多笔入账、自动保存、8 秒整批撤销、本地账本、月度统计
- 当前阶段：Android 内测，iOS / Android 共用 React Native 代码

## 必须展示

1. 按住说一句，系统实时听清。
2. 一句话生成多笔账，并自动分类；成片用两笔账单演示。
3. 松手后自动入账，不增加二次确认。
4. 8 秒内可以整批撤销。
5. 本地账本是主数据源，不使用登录作为记账前置。
6. 月度统计帮用户理解钱花在哪里。

## 不展示

- 微信登录、云备份、会员、支付等未完成能力。
- 真实用户量、商店已上架状态或虚构质量数据。
- 客户、个人或真实账单隐私；片中示例使用仓库既有公开测试句。

## 执行决策

| 需求 | 决策 |
| --- | --- |
| 画幅与时长 | 1920×1080，30fps，约 25.2 秒 |
| 创作路径 | video-shotcraft 自主自由创作，Remotion 实现 |
| 真实页面 | 使用仓库内已评审原型截图，不手搓重绘既有界面 |
| 视觉气质 | 奶油纸、暖墨、腮红、鼠尾草；冷静但不冰冷 |
| 音频 | 中文旁白 + 原创程序化配乐与拟音；响度标准化到 -16 LUFS，不使用来源不明的外部音轨 |
| 字幕 | 中文屏幕文案；不使用英文品牌填充词 |
| 差异化记忆点 | 64 根实时声纹先“听见”一句自然语言，再折成两笔真实账单 |
